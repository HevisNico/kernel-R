## First strong source at 24

`birth_first_strong_native_certificate` recovers the READY admission,
the raw occurrence at 24, the preceding total gain of 9/5, the exact
native FIRE, its unchanged due queue, and zero change of any gain or
recovery coordinate on the firing segment. The pre-birth router emits
no contact. This supplies the native branch evidence for the row.

The obstacle is the hypothesis of the existing network theorem.
Keep all native pending occurrences in the guarded queue and keep
each input address physical. The due-24 source is already present
while the due-0 source is read. Both have the same port and READY phase.
Hence their clean guarded reads agree at that initial memory. The
first weak source is silent, so the due-24 source would also be silent
if selected there.

The dated trace only selects earliest occurrences. However,
`PhaseAdmission.network_memory` takes `MarkFeedback.Admissible` on
the whole reachable MARK system. At each weak step its read-stability
property preserves the read of the still-pending due-24 source. After
the three weak steps it consequently requires silence at 24, in
conflict with the native FIRE. The same contradiction holds after
erasing any certified read errors to zero. Clipping at the reciprocal
horizon retains the due-24 source and all three earlier sources.

`birth_training_prefix_no_global_diamond` checks this impossibility
in Lean for any constants and any remaining decision word. The
obstruction concerns a refinement that preserves physical input
identity, admission phase and pending multiplicities and uses the
current global-diamond theorem. A nominal dated replay without that
global hypothesis is a different claim. This review stops at the
obstruction, leaving the network theorem and the native proof
unchanged.
