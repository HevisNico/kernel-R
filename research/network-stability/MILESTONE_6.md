# Milestone 6 — uniform conjunction on a ring

[FeedbackExamples.lean](FeedbackExamples.lean) proves the task for every positive size $N=n+1$. Seed one probe at cell zero. At cell $i$ the local input bit sets the port bias. A true bit fires and generates the next probe. A false bit writes once and stops propagation. After the last true input, its FIRE generates an acknowledgement probe back at cell zero. The acknowledgement fires and emits nothing. The graph on cells is a directed ring, including a self-contact at size one. Probe types distinguish the input visit from the acknowledgement. Progress through those types supplies the decreasing rank on a cyclic cell graph.

The constants are the same at every size.

| Quantity | Value |
| --- | ---: |
| Per-cell seed reserve $Q$ | 2 |
| Dose $d$ | 1 |
| Initial stored memory and uniform bound $B$ | 1 |
| Strict upper rail $U$ | 4 |
| Scalar seed coefficient $W$ | 2 |
| Scalar decrement $\eta$ | 1 |
| Absolute read error bound | 1 |
| Maximum routed score contribution | 1 |

The initial probe carries scalar weight $N+1$, including the possible acknowledgement, so it meets $N+1\le 2N$. Each input cell can receive one input probe, and cell zero can also receive the acknowledgement. That gives the uniform local reserve. The nominal margins hold because every probe with a successor fires without writing, and the first false bit has enough silence margin even with the routed contribution and positive error.

Under every read-error trace in $[-1,1]$, the acknowledgement is present exactly when all $N$ inputs are true. The terminal state is identical to the clean run and the memory remains within the rail. Scheduling uses only the initial probe; the return is generated by the final input FIRE. The implementation encodes a one-lap protocol in the probe types, with no unbounded recirculation claim.
