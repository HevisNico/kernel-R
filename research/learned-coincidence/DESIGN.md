# Phase 0 · Pattern recognition by learned coincidence

## Task and class

A layer broadcasts a pattern $S\subseteq\{0,\ldots,M-1\}$ to $N$ independent cells during tests. Output $i$ recognizes the presence of its target feature set $T_i$. The targets are joint patterns with at least two active inputs. Each training round presents only $T_i$ to cell $i$, with its ports admitted simultaneously and time to settle before the next round. Thus cells can train concurrently even when they receive different patterns. The tester broadcasts a common pattern to all cells, with writes disabled.

[Target.lean](Target.lean) defines the parameter checker. Its inputs are bit patterns, held-out patterns, nonnegative initial gains, a fixed help term and threshold per cell, error budgets, a positive common dose, a per-port write budget $Q$, and a rail. No execution or log enters the checker. The held-out suite contains no training pattern. Each target has a nonempty proper subpattern and a proper superset in the held-out suite. The suite also includes a pattern incomparable with every target.

For example, use targets $\{0,1\}$, $\{1,2\}$, $\{2,3\}$ with four inputs. Keep all singletons, $\{0,2\}$, $\{1,3\}$, $\{0,1,2\}$, $\{0,2,3\}$, and $\{0,1,2,3\}$ for tests. The target sets form an antichain. The expected outputs can still overlap on held-out supersets.

| Held-out pattern | Expected active outputs, indexed from 0 |
| --- | --- |
| Any singleton, $\{0,2\}$, or $\{1,3\}$ | None |
| $\{0,1,2\}$ | 0 and 1 |
| $\{0,2,3\}$ | 2 |
| $\{0,1,2,3\}$ | All three |

## Guarded model and frozen target

The joint score is $h_i+\sum_{j\in S} g_{ij}$, where the help $h_i$ is fixed across the patterns and both modes. FIRE means score plus signed read error $e$ is at least the cell's threshold. A silent training read atomically adds one dose to every active target gain. FIRE has an empty write footprint. The local update inspects only the observed decision. The pre-run predictor computes the first nominal crossing $k_i$ by checking $0,\ldots,Q$ using the gain path obtained from $k$ silent rounds. It supplies a prediction, and the repeated input drives the stop.

The checker requires $1\le k_i\le Q$, a strict silence margin at every $k<k_i$, and a FIRE margin at $k_i$, with the closed training error interval $[-\varepsilon_i^{\rm train},\varepsilon_i^{\rm train}]$. The upper guard must satisfy $\mathrm{score}+\varepsilon<\theta$ for silence. $\mathrm{score}-\varepsilon\ge\theta$ suffices for FIRE, including equality. All settled gains are strictly below the rail. For tests, certify FIRE at $T_i$ and silence on the full input set with each $j\in T_i$ omitted, using $[-\varepsilon_i^{\rm test},\varepsilon_i^{\rm test}]$.

The frozen `LearnedCoincidenceRecognition` proposition says that every admissible training-error sequence produces exactly `min r k_i` silent reads before round $r$, followed by FIRE on every further target read. Each port stays below the rail, takes at most $Q$ writes, and its gain settles by round $Q$. After $Q+1$ presentations, including the last possible first FIRE, every read-only test under its error budget returns the predicted output. The test clause covers the whole Boolean cube. The proof plan is induction on the number of rounds, followed by comparison with the certified extremal patterns. The checker and worked examples compile in Phase 0.

## Exactly what this class can learn

Nonnegative gains and fixed help make the score monotone in the active set. A cell certified to fire on $T_i$ therefore fires on its supersets. Any set missing a target input is contained in the full set omitting that input. Its score is bounded by the corresponding certified silence score.

For a given valid target list the response of each output is therefore exactly the conjunction of its target bits, with positives forming the principal upward-closed set generated by $T_i$. This design realizes precisely vectors of such conjunctions, subject to the joint-target and held-out coverage requirements. On a specified test domain, take the restrictions of those functions to that domain. For any target list with the required coverage, zero starts and help, dose 4, error radius 1, rail 5 and $Q=1$ suffice. Set the threshold of a target of size $m\ge2$ to $4m-2$. The first round is silent. The target score becomes $4m$ and a pattern missing any target input scores at most $4(m-1)$.

This rules out exact equality to a target against its strict supersets, XOR, and an output with two incomparable minimal positive patterns. Several cells can report those two conjunctions separately. A downstream OR would be a different architecture. For one-hot use, only choose a test domain in which no pattern contains two targets. The pilot instead predicts multiple hits explicitly.

## Native refinement plan

[`trained_coincidence_network`](../recursive-learning/native/Training/TrainedCoincidence.lean) starts with **separate** per-port training trains, then makes a joint read on each cell of a pair and compares FIRE dates. Its result supplies local read and product techniques. This track needs a new joint training transaction that learns from a single read of the active set.

1. At a settled READY cut, consume all same-date arrivals in a batch and show their interleavings yield the same active set before any flow. Relate the native drive $\sum_j \exp(z_{ij})I_j(t)$ and recovery or static bias to the guarded scalar score. Certify a margin for the first crossing or for silence over the entire read, with an explicit skew and reset window. The linear guarded gain is an effective read contribution. The native ERROR dose is in log-gain and gives a multiplicative change of amplitude. A bridge must certify the increment in score units over the full gain trajectory, or establish an equivalent calibrated encoding.
2. Generalize the weak and strong local legs to a batch *on the same cell*. Silence must commit one full ERROR dose on each active port and zero everywhere else. FIRE must yield the empty write footprint, including recovery. A simultaneous arrival can leave another sensor in a phase that could lead to MARK. Check guard ordering, ERROR completion, MARK exclusion, clipping, raw expiry, and restoration of READY at the same cut. Reuse the scalar legs of [NativeWeakStep.lean](../network-stability/NativeWeakStep.lean) and [NativeStrongStep.lean](../network-stability/NativeStrongStep.lean) as the one-active-port cases. Provide an explicit test read gate that blocks ERROR and MARK writes on every tested branch, including silent tests.
3. Weave certified one-cell legs over each round with [`synchronized_execution`](../native-multitoken/SynchronizedProduct.lean) and [`synchronized_ledger`](../native-multitoken/SynchronizedProduct.lean). Admit the batch first, since the synchronization theorem takes legs with no deliveries inside the segment. Carry future sources and use an empty output router for this observation layer. Reconcile both gain and recovery ledgers and compose rounds. This product handles different cells, while the same-cell batch above supplies the needed joint physics.
4. The current native `Port` is `Fin 3`. A first native target can use three input lines with two-port targets, for example $\{0,1\}$ and $\{1,2\}$. A direct four-to-six-input target needs generalized native port semantics or a front end exposing distinct, independently trainable gains. Any such front end needs its own simultaneous-batch refinement and write-footprint certificate.

## Circuit measurement and cost

The nominal Sky130 simulation records a joint FIRE at **0.2675** units. The same-date ideal window is **(0.239, 0.256]**. At 20 µs per unit, the nominal FIRE misses the ideal deadline by 0.23 µs. The existing 100-cell simulation reports 0.2595–0.2730 for its two-port joint read. These measurements describe the simulated two-port setup. Four-to-six-input coincidence still needs calibration. A decoder using the ideal 0.256 deadline would record a false negative on the nominal joint trace. [Circuit verdict C5](../circuit/VERDICTS.md) · [Circuit campaign and time unit](../circuit/README.md) · [Ideal joint-read theorem](../recursive-learning/native/Training/JointRead.lean)

The prediction needs measured **decision margins and timing**. Record raw input arrival dates, whether FIRE occurred and when, start and settled gain and recovery, per-port dose, and the start of the next READY window. Calibrate help and individual contributions from empty and singleton reads. With independent calibration traces, bound the joint-score residual (including skew and nonadditivity) over the tested histories and operating conditions. Use a matched guard-disabled charge probe or independently calibrated pre-FIRE score observable when reset clips the apparent peak. Validate that instrumentation against ordinary FIRE traces. Check silence over the full response window, and check write inhibition on silent and firing test trials. Predeclare the calibration and validation split, the observation and settlement deadlines, and the required margins before the held-out campaign. The observed 0.2675 is a starting point for that window, and the window must also detect late unwanted FIREs. A sampled residual gives empirical evidence over the sampled cases. Certifying an entire PVT, skew or disturbance interval requires an independent enclosure.

A full-cube pilot has these planning costs. It assumes a parallel deck with all $N$ cell outputs, independent restored trained checkpoints, three PVT settings and three fixed skew waveforms (aligned and two opposed offsets), one calibration repeat and five fresh validation repeats per setting. Training targets in a full-cube sweep are controls outside the held-out scorecard.

| --- | ---: | ---: | ---: | ---: |
| 4, 4 | 16 | 64 | 864 | 3,456 |
| 6, 5 | 32 | 192 | 1,728 | 10,368 |

Empty and singleton captures are included in the table. Budget another 54 training histories (one per setting and repeat), with up to $Q+1$ rounds per history if all cells train in parallel. Capture the joint score margin and per-port gain change at each training stage on the calibration histories. Saving and restoring a checkpoint requires a repeatability check, including the rested sensor state. If each test needs fresh training instead, attach that training to each transient and time the combined deck. The full pilot is 918–3,510 transient jobs with separate checkpoint preparation. At one second per job this is about 0.26–0.98 serial CPU-hours. At ten seconds it is about 2.6–9.8 CPU-hours, before extraction, layout and analysis. If the charge proxy requires a second calibration deck, budget up to another $9\,2^M$ transients. These rates are planning scenarios. Benchmark a small batch on the actual expanded deck. For later screening the guarded checker only needs the target and one maximal omission per target input, a total of $\sum_i (1+|T_i|)$ cell-pattern pairs. Reducing physical measurements to that set requires a separate justification that the physical response is monotone or within a certified residual envelope.

## Controls

Each checker condition has a rejection example in Lean. The counterexamples about execution and measurable outputs specify the actual failure, while coverage controls describe the missing comparison.

| Condition | Control and consequence |
| --- | --- |
| Positive dose | Set dose to zero in the pilot. Scores stay at their initial values and the positive targets remain silent. |
| Joint target | Replace the targets with a singleton. Any learned FIRE is a one-line detection, with no joint feature required. |
| Held-out disjointness | Add a training target to the tests. Its success would report training performance as held-out performance. |
| Proper subpattern per target | Remove the singletons. The suite misses the one-active-port failure mode. |
| Proper superset per target | Keep only patterns of size at most two for the pair targets. The suite misses all positive tests. |
| Unrelated test | Keep just the singletons and the full pattern. No incomparable read checks spurious firing from a different combination. |
| Early silence margin | At threshold 10, two doses are predicted. Score 8 with error $+2$ fires before the second dose. |
| Robust stop within budget | Set (Q=0) for the pilot. The first read is silent and a required write lies beyond the budget. |
| Rail headroom | Set the rail to 4. One correct dose lands at the rail. |
| Positive test margin | At threshold 7 the settled target score 8 falls to 6 under error $-2$. A held-out superset is missed. |
| Negative test margin | At threshold 6 a singleton scores 4. Error $+2$ causes a false FIRE. |

Further semantic controls are useful for the later bridges. Treating silent tests as training would add a dose on a singleton and change later outcomes. Allowing negative gain on an extra input could make a target fire and its superset silent. In the accepted pilot, the untrained layer reports three silent outputs on $\{0,1,2\}$ instead of the two predicted hits. The ideal-deadline decoder on C5 is the independent circuit timing control above.
