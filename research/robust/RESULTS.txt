LIMITS
The universal-N result is a written comparison/packet-induction argument with
integer-checked inequalities. It is not a complete Lean proof. Numerical tests
alone do not establish a theorem for arbitrary measurable disturbances.
The prepared slow-input chain is covered; the original fast period-4 packet
protocol, entry from birth, feedback, losses and arbitrary waveforms are not.
No GitHub writes were made. All package text and code are in English.
