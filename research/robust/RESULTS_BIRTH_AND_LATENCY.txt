INTERMEDIATE SCALING RESULT
For the same cell's actual learned-gain reference latency, regular phase error
is bounded by delta_i. The sufficient input period is
  T >= 7.5 + 2 sum_(i=0,...,N-2)(sigma_i + delta_i).
The final cell's radius enters output jitter but not an absent successor's input.
The first residual firing is handled as a nonnegative advance plus a bounded
delay error; the incoming exceptional prefix is removed during local learning.
At zero noise and zero amplitude variation, delta=0 exactly.

For epsilon=.1, nu=.002, alpha=0, the certified uniform radius is .00748.
For N=32 and fixed wires this gives T>=7.96376. Two independent history families
passed full birth-to-chain runs at T=8, yielding eight root outputs each.
The previous coarse bound was T>=23. The improvement does not assert a constant
period for unlimited depth with nonzero uniform delta.

The guessed radius .003 is not sound uniformly over arbitrary long quiet gaps:
an integer-interval test gives a reference crossing above .653 and an admissible
perturbed crossing below .650. The bound .00748 covers this longer-wait scope.
At large amplitude deviation the symmetric-radius method can be conservative;
the old full-envelope sufficient bound is still available. Stored certificates
cover eight points; there is no unchecked interpolation between them.
