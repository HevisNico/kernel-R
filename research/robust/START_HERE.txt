Robust N-cell extension — offline, English-language deliverable

1. periodic/THEOREM.md: stronger result with zero charge noise and identical
   pulses. A constant period T >= 7.5 works for arbitrary finite N with fixed
   wires. With wire phase budgets sigma_i, use T >= 7.5 + 2 sum sigma_i.
2. THEOREM_N.md: conservative bound for the fully disturbed local model,
   T >= 7.5 + 0.5(N-1). This still covers nonzero bounded noise/amplitude changes.
3. README.md: baseline implementation and reproduction commands.
4. periodic/README.md: stronger extension, separate reproduction/evidence.

Both results concern prepared slow-input chains. Neither extends the original
fast-packet protocol from birth. The proofs are written comparison/induction
arguments with integer-checked inequalities, not a complete Lean verification.
Nothing has been pushed to GitHub.
