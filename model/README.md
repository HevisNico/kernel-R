# Kernel R model

- [Cell laws](CELL.md) specify the dynamics and events of one R cell.
- [Finite-chain protocol](CHAIN_PROTOCOL.md) specifies the inputs, routing and

- [Implementation assumptions](IMPLEMENTATION_ASSUMPTIONS.md) list what a

  written definitions to the verified ones.
- The [historical A22 specification](../archive/spec-216-cells/README.md)
