This project checks mathematical lemmas and finite evidence with Lean 4.35.0 and
Mathlib v4.35.0. It is a **partial formalization**. The physical three-cell
protocol is now constructed from A's original READY birth through **789.9**,
with cumulative **A54/B61/C34** and cadence counts **A16/B18/C20**. Both

retain their639.9 teaching values. No later reaching execution, received

reaching-execution, calendar or local-law premise. See
[the every-N construction below](#constructed-common-birth-chain-for-every-finite-n).
Every complete finite execution of the fixed common-birth program now has the
same physical endpoint and exact per-cell FIRE dates. The
[geometric correspondence](../../docs/MODEL_LEAN_CORRESPONDENCE.md#threshold-contacts-and-upward-crossings)

## Every complete finite execution of the fixed program

`every_finite_chain_every_complete_execution`, `terminal_state_and_counts`

> For every admissible positive finite N, K, independent fixed fabrication and
> birth data, and bounded prescribed error family, there exist fixed native
> delay functions and a constructed complete witness, such that **every finite
> execution from the same initial state under that fixed router, complete at
> the declared T**, has the claimed physical endpoint, memories, counts and
> prescribed errors at its own actual fast-phase sending FIREs.

Existence is retained, so the universal class is nonempty. `CompleteThrough e T`
requires terminal date T, no enabled terminal jump and no token due by T still
pending. It is a condition on a supplied finite operational execution, not a
proof that a stopped prefix must progress, a maximal infinite run reaches T,
or Zeno behavior is impossible.

proves this observational comparison for any fixed finite network, parameter
family and router, with `PhysicalBox` and initial `PhysicalInvariant`:
complete executions through the same T have equal time, physical coordinates,
main/auxiliary modes and RAW state, pending queues related by permutation, and
**exactly equal ordered per-cell FIRE-date lists**. The global emission list is
compared up to permutation, allowing legal simultaneous interleavings. Neither
flow subdivision nor the syntactic order of independent instantaneous moves
is made unique. No event-priority, target calendar or determinism premise is
added to the protocol theorem.

[HybridUniversalBirthCadenceChain](KernelR/HybridUniversalBirthCadenceChain.lean)

### Rebuild project proofs without a restored project cache

A successful incremental build may replay diagnostics from cached artifacts;
it does not necessarily recompile every project module. For an independent
source rebuild, use a fresh checkout and replace `COMMIT_SHA` below with the
full commit being audited. The destination must not already exist.

```sh
git clone https://github.com/HevisNico/kernel-R.git kernel-R-clean
cd kernel-R-clean
git checkout --detach COMMIT_SHA
git rev-parse HEAD
cd proof/lean
lake exe cache get
lake build

```

Do not copy or restore the project's `.lake/build` directory into this checkout.
`lake exe cache get` fetches dependency artifacts; the commands above rebuild
the project's proofs, not the Lean toolchain or all third-party dependencies
from source. Record the commit, `lean --version`, build log and axiom-audit
output, and distinguish this run from a cached CI replay. Then run the source,
evidence and paired controls listed above for the full validation suite.

## How the evidence is connected

`scripts/generate_evidence.py` reads the eight certificates already in
[results](../../results) and the adaptive evaluation inside the repository's
[pinned prototype ZIP](../../downloads/R_Reciprocal_Prototype.zip). It validates
the ZIP and its manifest using the existing repository verifier. It does not
duplicate the raw recordings. Input SHA-256 identities are recorded in
[GENERATED_FROM.json](evidence/GENERATED_FROM.json).

The emitter converts decimal strings to exact rational literals. Lean proves
each emitted inequality with `norm_num`, and the finite replay with `decide`.
The emitter is not in the logical trust base of these individual propositions:
a wrong inequality cannot acquire a valid proof through code generation. The
correspondence between the emitted proposition and the intended model still
needs review; hashes and regeneration checks establish provenance, not semantics.

The adaptive records have been recomputed with the complete source/runtime
manifest on the original seeds. The emitter checks the bundled source hashes,
runtime metadata and actual learned policy before extracting outcomes. The
plan and policy hashes are recorded alongside the evaluation hash.

The adaptive replay uses the explicit stop rule equivalent to the reported
learned policy on these records. Python also checks the retained success flags
against the saved eight probe windows. That extraction check uses the original
numeric recordings; Lean proves only the resulting finite Boolean/list claims.
Teacher-query pulses remain separate from the reported student pulse totals.

## C → B → A extension

The cadence theorem requires more than reusing the earlier three-case cycle
model. `Cadence.PulseCase.markThenError` gives one MARK dose and one ERROR dose
without an emission. `CadenceRecorded` checks the accumulated counters after
**every** input, including those combined cases. The old `Protocol` abstraction
retains its original, narrower scope.

The new analytic lemma integrates the exponential MARK profile to obtain
`(b + 0.1) * u - J`, with
`J = 0.1 * tau + (0.1 - 0.4 * log(5/4)) / Lm`. The return identity uses that
deficit; it does not approximate MARK as an instantaneous jump in recovery.
The abstract `Cadence` lemma requires the physical phase ordering as a premise;
the `Hybrid*` local cases and cadence constructors derive their own guards.

Shared firing latencies can cancel between dates, but fresh per-pulse wire
delays cannot. The new calendar lemma retains `d₂ - d₁` and proves the
[3.9,4.1] gap bound for a period-4 source and one wire with delays in [0.3,0.4],
or [3.8,4.2] for the two-wire C→B→A path with shared latencies.
A checked counterexample prevents an exact period-preservation claim under
independent jitter. This bound applies to the stated common-latency case;
skipped emissions and changed gains need their own calendar hypotheses.

The two cadence certificates add 2,060 strict comparisons and 5,066 interval
validity checks. Their generated files are split into chunks of at most 160
checks, with aggregate theorems importing every chunk. This limits individual
compilation size while preserving the exact published inputs. Neither the
retained 4/8→8/8 probes nor the causal cuts are upgraded to complete Lean
theorems of the hybrid system by this arithmetic/trace replay.

## Every finite N: compositional extension

The [N-cell coverage guide](N_CELL_COVERAGE.md) maps the written argument to
`Chain.Packets`, `Chain.Induction`, `Chain.Refinement`, `Chain.Algebra` and
`Chain.Consequences`. Lean checks packet-date closure, induction for arbitrary
finite depth, nonuniform jitter budgets, natural emission/traffic counts, dose
words, conditional cut propagation and terminal-time bounds. Both N-cell
certificates add 162 exact endpoint comparisons and 352 interval-validity checks.

The separate common-birth physical construction now supplies preparation,
leaf packets, full-budget receivers and actual causal composition for every
finite N. `HybridPreparedCadenceChainConstruction` invokes these factories
inside the packet induction. The older `Chain.Refinement.realized_chain`
retains its explicit leaf and narrower `RelayLaw` premises. The new construction
uses the directly proved broad physical closure; it does not discharge that
older signature or soundness of every stored certificate enclosure.

## What remains to close the complete proof

1. Extend the declared common-birth/source/port family where the full written
   statement requires it. Arbitrary bounded prescribed per-emission error
   sequences now have a complete physical birth-to-terminal realization.
2. Prove the remaining real enclosure memberships, retained probe responses
   and settings-copy semantics. Finite-prefix continuation is proved for the
   declared finite-source program, including its crossing histories; indefinitely
   repeatable responding network operation remains open.
   Stored endpoint comparisons do not establish these facts.
3. Extend robustness to operational drift/noise/amplitude histories in the
   physical semantics, beyond the conditional analytic coverage.
4. For pedagogy, separately formalize the observation/readout/training interface
   and connect numerical records to that semantics.

[entry theorem](../reciprocal_entry/THEOREM.md) and

formalization and its exact boundaries are detailed in the
